# Dürrenmatt — annotated examples

Concrete voice exemplars used to ground generation and the Author-Voice checker. Each example =
the text + *why it works*. Seeded from `../profile.yaml` (`examples:` block); extend with more.

## 1. Philosophy (contingency as world-principle)
> "Der Zufall spielt in meinen Stücken eine große Rolle; denn unsere Welt erscheint mir als eine der
> möglichen Welten, nicht als die notwendige, als eine zufällige."
*Why:* states the worldview plainly — the world is contingent, not necessary.

## 2. Description (laconic + philosophical aside + irony)
> "Der Zufall hatte gesprochen, wie er immer spricht: ohne Sinn, ohne Moral, ohne jeden Respekt vor
> dem, was wir Gerechtigkeit nennen." *(Das Versprechen)*
*Why:* horror rendered as flat report, with a paradoxical aside that undercuts "justice."

## 3. Dialogue (exposes bourgeois morality)
> «Ich bin krank», sagte Ill. «Ich habe Angst.» — «Wir haben alle Angst … aber das ist kein Grund,
> sich zu beklagen. Wir tun unsere Pflicht.» *(Der Besuch der alten Dame)*
*Why:* the reply answers past the speaker; duty-talk masks complicity.

## 4. Opening rhythm (statement → paradox → inevitability)
> "Die Stadt lehnte ab. Die Stadt empörte sich. Die Stadt würde annehmen. Das war unvermeidlich, wie
> das Wetter." *(Der Besuch der alten Dame)*
*Why:* the signature cadence — accumulation that makes the grotesque feel inevitable.

## 5. Generated exemplar (this project, `novels/der-chrachen/`)
> "Die Formel kam ihm von selbst, wie einem Zimmermann das Maß kommt." … "Es widerspricht selten
> jemand einem Satz, der so bequem ist."
*Why:* an on-target v2 target — a grotesque act rendered as ingrained procedure, irony from arrangement.
