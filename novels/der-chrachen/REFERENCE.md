# der-chrachen — v1 reference capture

This folder is the **1:1 simulation run** of the *old* (v1) pipeline (moved here from
`story_output/pipeline_capture/` during P0). Its internal structure is the original phase-numbered
capture — it predates the v2 `novels/<slug>/` layout in `../README.md`, and is kept as reference and
as the evidence behind the findings.

- `README.md` — the run index + synthesis + prioritized fix list
- `FINDINGS.md` — F1–F12 (the problems that motivated the v2 redesign in `/DESIGN.md`)
- `DIVERGENCE.md` — where the readable novel differs from what the v1 pipeline would ship
- `novel.md` — the readable 3-chapter Dürrenmatt novella *"Der Chrachen"*
- `00_…/ … 07_…/` — per-agent filled prompts + artifacts

The first novel built with the **v2** pipeline will use the new layout instead.
