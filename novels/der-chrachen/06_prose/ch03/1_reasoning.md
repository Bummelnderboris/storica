# ARTIFACT — Phase 6, Ch3, Step 1: Prose Reasoning (Sonnet)

1. **Voice:** auktorial-personennah, eng an Stettler, ohne Introspektion — nur Wahrnehmung/Handlung/Objekte. Präteritum, parataktisch, funktionale Adjektive (Eiche, Blech, Papier). Ironie aus Gegenüberstellung, nie Erzählerwertung.
2. **Opening:** direkt in Szene 1, Bericht auf dem Tisch; Kälte über Objekte (Papier, Feder, Tinte), nicht Naturbeschreibung; erster Satz amtlich-knapp.
3. **Transitions:** vier harte Schnitte über Ortswechsel (Büro → Amtsschalter → Kirchvorplatz → Aktenkeller); jede Szene endet auf Handlung/Objekt, nicht Gefühl.
4. **Dialogue:** protokollarisch knapp. Feuz referiert Formalia, streut den Vogel-Kommentar beiläufig ein. Berta: ein Feststellungssatz. Stettler: „Ja." Rutz: „Kalt heute.", kein Name (Unterlassung = Distanz). Keine Adverb-Tags.
5. **Pacing:** verlangsamt szenenweise bis zur zeremoniellen Schlussszene (Einsortieren minutiös registriert); nur eine Richtung — hinein ins Erstarren.
6. **Challenges:** Vogel-Erwähnung beiläufig (Wirkung durch Stettlers NICHT-Reaktion); Rutz' Nicken undeutbar lassen; Schlussbild als reine Fakten (kein „wie ein Gefängnis"); Verdichtung auf ~1000 Wörter.
7. **Key Moments:** kratzende Feder (Echo, kein Wort); Bertas Satz + „Ja." + Abgang ohne Umdrehen; Rutz' „Kalt heute." + minimales Nicken; Schlussbild zwei Aktendeckel, gleiche Hand, Schloss klickt (letzter Laut), verzerrtes Spiegelbild im Blech; letzter Satz nüchtern-amtlich.
8. **Consistency:** Rutz = Pfarrer (keine Beichte vollzogen); Stettler = Amtsarzt (zeichnet, verhört nicht); Melchior = Sturz, keine Vergiftung/Obduktion; Opfer = Klara Vogel; Berta = Witwe; kein Geständnis/Verhaftung — offenes Ende, Gefängnisbild nur über Schrank/Schloss/Spiegelung.
